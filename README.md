THE SPOT — a spot-the-difference game: two nearly identical pictures, 7 hidden differences per level, across Morning Park, Sunset Beach and Afternoon Café. Find them all before time runs out.

Click a difference in the left picture or the right one — both count. A correct click draws a green circle and scores points; a wrong click costs a heart. Each level gives you 3 hearts, 2 hints and 90 seconds, with a time bonus when you clear it.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Or open `game/index.html` directly — the game is static files and plays offline.
